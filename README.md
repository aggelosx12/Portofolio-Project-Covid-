🦠COVID-19 Data Exploration & Visualization (SQL Project)

This project analyzes global COVID-19 data using SQL Server. It explores infection rates, death ratios, and vaccination progress across countries and continents. The results serve as a foundation for dashboards and data storytelling.

📁 Dataset Sources
COVID-19 Cases & Deaths
COVID-19 Vaccination Data

🎯 Objectives
✔ Analyze COVID impacts across countries & continents
✔ Calculate infection and death percentages
✔ Compute rolling (cumulative) vaccination metrics
✔ Use SQL best practices and analytical techniques
